# Neovim キーボードショートカット一覧

LazyVim（extras なし）で使えるキーボードショートカットの早見表です。

この設定は「モードレス」です。通常のファイルを開くと、そのまま文字を打てます（インサートモード）。`Esc` を押してもノーマルモードには戻りません。Vim のコマンドを使いたいときは `Ctrl+O` を使います（「Vim のコマンドを使いたいとき」を参照）。ヘルプ・ファイル一覧・ダッシュボード・quickfix など、編集できない特殊な画面は従来どおりノーマルモードです（インサート中にそうした画面へクリックで移っても、自動でノーマルモードに戻ります）。

## 記法

| 表記 | 意味 |
| --- | --- |
| `<leader>` | Space キー（`<leader>ff` は Space を押してから `f` `f`） |
| `<localleader>` | `\` キー |
| `<C-x>` | Ctrl + x |
| `<S-x>` | Shift + x |
| `<M-x>` / `<A-x>` | Option（Alt）+ x |
| `<D-x>` | Cmd + x（Ghostty と Neovim 0.10 以降で届く） |
| `<CR>` | Enter |
| `<Esc>` | Esc |
| `<Tab>` | Tab |

- 起動は `nvim`。`nvim .` でカレントディレクトリを開きます（`neovim` ではなく `nvim`）。
- 迷って Space を押すと文字が入ります（インサートのため）。which-key を見たいときは `Ctrl+O` の後に押すか、ファイル一覧など特殊な画面から押します。
- `<leader>sk` でキーマップを検索できます（同じく `Ctrl+O` の後か特殊な画面から）。
- モード欄：n = ノーマル、i = インサート、v = ビジュアル、x = ビジュアル（矩形を含む）、s = セレクト、o = オペレータ待ち、c = コマンドライン、t = ターミナル。

## よく使うもの

普段の作業はほぼこの節だけで足ります。

### 画面の開閉

| キー | 説明 |
| --- | --- |
| Cmd+J（または `<C-/>`） | 右側のターミナル列をまとめて開く / 隠す（入力中・ターミナルの中で押しても効く。プロセスは残る） |
| Cmd+Shift+J | 右側のターミナルの一番下に新しいターミナルを追加する（隠れていれば先に全部戻す。1 つも無ければ右側に 1 つ目） |
| Cmd+B（または `<leader>e` = Space → e） | 左側のファイル一覧（エクスプローラー）を開く / 閉じる（入力中・ターミナルの中で押しても効く） |
| ウィンドウのクリック | ファイル一覧・エディタ・ターミナルの間はマウスでクリックして移れる（`<C-h>` / `<C-l>` でも左 / 右へ移動） |
| Cmd+T | Ghostty の新しいタブを開く（Neovim を開いたままでも使える。Ghostty 側の操作） |

### マウス操作

| 操作 | 説明 |
| --- | --- |
| クリック | クリックした位置にカーソルを移す（そのまま入力できる） |
| ドラッグ | 範囲を選択する（選択中に文字を打つと置き換わる。シフトなしの矢印で選択解除） |
| ファイル一覧のクリック | 1 回でファイルを開く / フォルダを開閉する（エディタ側に開いてそのまま入力できる。ダブルクリックでの確定は無効。エディタで入力中にクリックしても効く） |
| タブ（bufferline）のクリック | そのファイルに切り替える（右クリックはそのファイルを閉じる） |
| ホイール | スクロール |
| ウィンドウの境界線のドラッグ | ウィンドウの大きさを変える（ステータスラインや縦の区切りをドラッグ） |
| 右クリック | ポップアップメニュー（`mousemodel=popup_setpos` の既定。タブの上ではバッファを閉じる） |
| Shift+ドラッグ | Ghostty 自体の選択（画面の文字を選んでコピーしたいとき。Neovim には渡らず Ghostty が選択する） |

### 編集

| キー | 説明 |
| --- | --- |
| そのまま打つ | カーソル位置に入力する（インサートモードのまま） |
| Shift+矢印 / マウスのドラッグ | 選択を開始・広げる（そのまま打つと選択範囲が置き換わる） |
| Cmd+S | 保存する（入力したまま） |
| Cmd+Z / Cmd+Shift+Z | 元に戻す / やり直す（入力したまま。選択中に押したときは選択を解除してから戻す） |
| Cmd+C / Cmd+X | 選択範囲をコピー / 切り取り（選択が無いときは何もしない） |
| Cmd+V | 貼り付け（Ghostty の貼り付けがそのまま使われる） |
| Cmd+A | 全体を選択する（続けて打つと全体が置き換わる） |
| `Esc` | 補完メニューを閉じる・検索のハイライトを消す（ノーマルモードには戻らない） |

undo はスペース・改行・入力が止まったところで区切られます。

### 探す

| キー | 説明 |
| --- | --- |
| Cmd+F | 今のファイルの中を行検索（Snacks の行検索ピッカー） |
| Cmd+P | ファイル名で検索して開く（ルートディレクトリ） |
| タブ（bufferline）のクリック | 開いているファイル（バッファ）を切り替える |
| `<leader><space>` など | ノーマルモードの検索（特殊な画面や `Ctrl+O` の後で使う） |

Cmd キーは、Ghostty の設定（`ghostty/keymaps.ghostty`）と Neovim 0.10 以降の kitty キーボードプロトコルにより、`<D-s>` などのキーとして Neovim に届きます（Cmd+J・Cmd+B は制御文字、Cmd+V は Ghostty の貼り付けを使うため、この限りではありません）。Cmd+Shift+文字は `<D-Z>` のような大文字のキーとして届きます。Ghostty 以外のターミナルでは効きません。ターミナル（`t` モード）の中には Cmd+C / Cmd+V などを定義しておらず、シェルに任せています（Cmd+J と Cmd+Shift+J は効きます）。

### ファイル一覧（エクスプローラー）の中で

| キー | 説明 |
| --- | --- |
| クリック | 1 回でファイルを開く / フォルダを開閉する（エディタ側に開いてそのまま入力できる。ダブルクリックでの確定は無効。ファイルを開いても一覧は開いたまま。エディタで入力中にクリックしても効く） |
| `j` / `k`（または ↓ / ↑） | 下 / 上へ移動 |
| `<CR>`（Enter）または `l` | ファイルを開く / フォルダを開く |
| `h` | フォルダを閉じる |
| `a` | ファイルを新規作成（名前の末尾を `/` にするとフォルダ） |
| `r` / `d` | 名前を変更 / 削除 |
| `H` | 隠しファイルの表示を切り替え |
| `?` | ファイル一覧で使えるキーの一覧を表示 |

### 保存・終了

| キー | 説明 |
| --- | --- |
| Cmd+S | 保存（入力したまま） |
| `Ctrl+O` → `:w` + Enter | 保存 |
| `Ctrl+O` → `:q` + Enter | 閉じる |
| `Ctrl+O` → `:wq` + Enter | 保存して閉じる |
| `Ctrl+O` → `:q!` + Enter | 保存せずに閉じる |
| `Ctrl+O` → `:qa` + Enter | Neovim をすべて終了 |
| `<leader>qq`（Space → q → q） | Neovim をすべて終了（ファイル一覧など特殊な画面から） |
| `<C-s>`（Ctrl+s） | 保存（Cmd+S と同じ。保存後も入力できる状態のまま） |

### Vim のコマンドを使いたいとき

インサートのまま `Ctrl+O` を押すと、Vim のコマンドを 1 つだけ実行できます。実行後はインサートに戻ります。

| 操作 | 説明 |
| --- | --- |
| `Ctrl+O` → `dd` | 1 行削除 |
| `Ctrl+O` → `gg` | ファイルの先頭へ |
| `Ctrl+O` → `:q` + Enter | 閉じる |
| `Ctrl+O` → Space → q → q | `<leader>qq`（Neovim をすべて終了） |

`Ctrl+O` の後はノーマルモードのキーマップも使えるので、Space 始まり（`<leader>`）の LazyVim のキーも動きます。ふだん Space を押すと文字が入るのは、インサートのまま入力しているためです。

## Vim の基本操作

Vim 標準の操作です（LazyVim のキーマップ取得結果には出てきません）。この設定では普段は使いません。下のキーは、`Ctrl+O` の後か、ファイル一覧・ヘルプ・ダッシュボードなどノーマルモードのままの特殊な画面で使います。

### モードの切り替え

| キー | 説明 |
| --- | --- |
| `i` / `a` | カーソルの前 / 後ろから入力開始（インサートモード） |
| `o` / `O` | 下 / 上に新しい行を作って入力開始 |
| `Esc` | ノーマルモードに戻る（ファイル一覧など特殊な画面で。通常のファイルではインサートのまま） |
| `v` / `V` / `<C-v>` | 文字 / 行 / 矩形のビジュアル選択 |
| `:` | コマンドライン（`:w` など） |

### 移動

| キー | 説明 |
| --- | --- |
| `h` `j` `k` `l` | 左 下 上 右 |
| `w` / `b` / `e` | 次の単語の頭 / 前の単語の頭 / 単語の末尾 |
| `0` / `^` / `$` | 行頭 / 行の最初の文字 / 行末 |
| `gg` / `G` | ファイルの先頭 / 末尾 |
| `<C-d>` / `<C-u>` | 半画面下 / 上へスクロール |

### 編集

| キー | 説明 |
| --- | --- |
| `x` | カーソル位置の 1 文字を削除 |
| `dd` / `yy` | 行を削除（切り取り）/ コピー |
| `p` / `P` | カーソルの後ろ / 前に貼り付け |
| `u` / `<C-r>` | 元に戻す / やり直す |
| `.` | 直前の変更を繰り返す |
| `ciw` | カーソルの単語を消して入力開始 |
| `dw` / `D` | 単語を削除 / 行末まで削除 |
| `>>` / `<<` | インデントを増やす / 減らす |

### 検索

| キー | 説明 |
| --- | --- |
| `/語` + `<CR>` | 下方向に検索 |
| `n` / `N` | 次 / 前の検索結果 |
| `*` | カーソルの単語を検索 |

### 保存・終了

| コマンド | 説明 |
| --- | --- |
| `:w` | 保存 |
| `:q` | 終了 |
| `:wq` | 保存して終了 |
| `:q!` | 保存せずに強制終了 |

## ターミナル

| キー | モード | 説明 |
| --- | --- | --- |
| Cmd+J / `<C-/>` | n, i, t | 右側のターミナル列をまとめて開閉（ルートディレクトリ）。表示中なら全部隠し、隠れていれば全部同じ順で戻す（プロセスは残る） |
| Cmd+Shift+J / `<D-J>` | n, i, t | 開いているターミナルの一番下に新しいターミナルを追加する（隠れていれば先に全部戻す。1 つも無ければ右側に 1 つ目） |
| `<leader>ft` | n | 右側のターミナル列をまとめて開閉（ルートディレクトリ） |
| `<leader>fT` | n | 右側にターミナルを開く（カレントディレクトリ） |
| `<leader>tv` | n | 右側にターミナルを縦分割で開く（toggleterm、カスタム設定） |

`<C-/>` `<leader>ft` `<leader>fT` は LazyVim 標準では画面の下に開きますが、`nvim/keymaps.lua` で右側（画面幅の 40%）に開くよう変更しています。Cmd+J はその列全体の開閉、Cmd+Shift+J は列の一番下への追加です。新しいターミナルの高さは均等に揃えます。ターミナルをクリックしてフォーカスすると、そのまま入力できます（`t` モード）。個別に閉じるときは、そのターミナルで `exit` と入力します。

Cmd+J は Ghostty の `ghostty/keymaps.ghostty` で Ctrl+/ と同じ制御文字（`<C-_>`）を送るよう設定したものです。Cmd 付きのキーは通常 Neovim に直接届かないため、Ghostty で制御文字に置き換えて送っています。Ghostty 以外のターミナルでは使えません。

Cmd+Shift+J は Ghostty の `super+shift+j` を unbind して、`<D-J>` として Neovim に届けています。Ghostty 標準の「画面の内容をファイルに書き出してパスを貼り付け」は使えなくなります。

Cmd+B も同じ仕組みで、Ghostty が Ctrl+^（`<C-^>`）を送り、`nvim/keymaps.lua` がそれを「ファイル一覧を開閉」に割り当てています。このため Vim 標準の `<C-^>`（直前のファイルに切り替え）は使えません。同じことは `<leader>bb` でできます。

ターミナル内で入力モードから抜けるには `<C-\><C-n>`（Vim 標準）。

## 省いたもの

- `<Plug>` / `<SNR>` で始まるもの、説明（desc）の無いもの、マウス関連（「よく使うもの > マウス操作」にまとめました）
- Neovim 組み込みの既定マップのうち日常的に使わないもの（`[a` `]L` `[<C-q>` などの引数リスト・Location List 系、`&` `Y` `Q` など）
- mini.pairs のカッコ・クォートの自動補完（`(` `"` など）と `<BS>` `<CR>` の補助マップ
- 矢印キーや `j` `k` の表示行移動、`<C-u>` `<C-w>`（インサートモードの Vim 標準）

## この一覧の作り方

2026-11-23 に、この設定で Neovim を headless 起動し、`nvim_get_keymap` でグローバルなキーマップ（説明付き 357 件）を取り出して整理しました。LSP と gitsigns のバッファごとのキーマップは LazyVim 本体のソースから補っています。「Vim の基本操作」節は Vim 標準の操作を手で選んだものです。

プラグインの更新で内容が変わることがあります。最新の状態は Neovim 内で `<leader>sk`（キーマップ検索）で確認できます。
